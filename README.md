<b>Ayomide Samuel</b> full-stack engineer with a habit of turning complicated ideas into software that feels simple to use. Across frontend engineering, backend systems, developer tooling, and AI-powered applications, the through-line is the same: getting something to work is only the starting point. What matters is that it stays maintainable, performs well, and is a pleasure to use.

<img src="https://skillicons.dev/icons?i=ts,js,react,next,node,python,tailwind,postgres,supabase,prisma,git" width="380" alt="Tech stack"/>

Most of my recent work has been aimed at developers themselves. Schemerr, an AI-powered deployment tool, takes the pain out of shipping apps to modern cloud platforms, and its CLI reduces the whole process to a single command. Moduly approaches a different problem: helping developers actually see how an application is structured, through interactive 3D visualizations, with its own CLI for exploring architecture from the terminal.

These days, i have been digging deeper into system design, backend architecture, and AI engineering, and is open to new opportunities. The goal stays constant: building software that solves real problems.
